# Final Project — Task Scheduler

## Описание проекта

Task Scheduler — это веб-приложение для планирования повседневных задач.

Приложение позволяет:
- создавать задачи;
- указывать дату выполнения;
- задавать правила повторения задач (ежедневно, по дням недели, по месяцам и т.д.);
- просматривать список задач;
- искать задачи по тексту и дате;
- редактировать и удалять задачи;
- отмечать задачи как выполненные. Для повторяющихся задач следующая дата выполнения рассчитывается автоматически.

Все данные сохраняются в базе данных SQLite, а для защиты API реализована аутентификация с использованием JWT-токенов.

## Запуск проекта локально

### 1. Клонируйте репозиторий

```bash
git clone <ссылка_на_репозиторий>
cd final_project
```

### 2. Создайте файл `.env`

В корне проекта создайте файл `.env` со следующим содержимым:

```env
TODO_PORT=7540
TODO_DBFILE=scheduler.db
TODO_PASSWORD=12345
```

Описание переменных:

- `TODO_PORT` — порт, на котором будет запущен веб-сервер.
- `TODO_DBFILE` — путь к файлу базы данных SQLite.
- `TODO_PASSWORD` — пароль для входа в приложение. Если оставить пустым, аутентификация будет отключена.

### 3. Установите зависимости

```bash
go mod download
```

### 4. Запустите приложение

```bash
go run ./cmd/app
```

После успешного запуска в консоли появится сообщение о запуске сервера.

### 5. Откройте приложение

Перейдите в браузере по адресу:

```text
http://localhost:7540
```

Если задан пароль (`TODO_PASSWORD`), сначала откроется страница авторизации. После успешного входа станет доступен основной интерфейс приложения.

> **Примечание:** если файл `.env` отсутствует, приложение автоматически использует значения по умолчанию (`7540` и `scheduler.db`). Для задания собственного порта, пути к базе данных или пароля рекомендуется создать файл `.env` и указать необходимые значения переменных окружения.

## Сборка и запуск проекта через Docker

### Сборка Docker-образа

Выполните команду в корне проекта:

docker build -t final-project .

### Запуск контейнера

docker run -d \ 
--name final-project \ 
-p 7540:7540 \ 
-e TODO_PORT=7540 \ 
-e TODO_DBFILE=/data/scheduler.db \ 
-e TODO_PASSWORD=12345 \ 
-v $(pwd)/scheduler.db:/data/scheduler.db \ 
final-project

### Описание параметров

-p 7540:7540 — пробрасывает порт контейнера на хост.
-e TODO_PORT=7540 — задаёт порт веб-сервера.
-e TODO_DBFILE=/data/scheduler.db — указывает путь к файлу базы данных внутри контейнера.
-e TODO_PASSWORD=12345 — задаёт пароль для аутентификации.
-v $(pwd)/scheduler.db:/data/scheduler.db — подключает файл базы данных с хоста, благодаря чему данные сохраняются между перезапусками контейнера.

После запуска приложение будет доступно по адресу:

http://localhost:7540/login.html
